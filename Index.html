📥 Importer un fichier de courses

Colonnes reconnues automatiquement : date, heure, montant brut/montant, paiement/mode, pourboire. Les fichiers Excel .xlsx et .xls sont aussi acceptés. Le fichier modèle inclus montre le format exact. Les lignes invalides sont refusées et signalées avant import.

💾 Sauvegarde et export

Tes données sont gardées uniquement dans ce navigateur. Si tu vides les données du site ou changes de téléphone, elles disparaissent : fais une sauvegarde de temps en temps.
« Sauvegarde complète » = toutes les entrées (fichier .json). « Restaurer » fusionne un fichier de sauvegarde avec tes données sans créer de doublons. « Exporter la période » = fichier CSV pour Excel ou ton comptable.
